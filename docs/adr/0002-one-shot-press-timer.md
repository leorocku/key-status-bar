# 一次性按键按下计时：接受合法长按抖动，换取释放丢失修复

最常见的故障是释放信号丢失：键盘已物理释放，但主机状态表停留在"按下"，内核输入路径持续合成重复按键（自动重复）——这就是卡住的键持续打字的原因。因此卡住的键在钩子层会持续产生重复按下事件，与用户合法长按产生的重复事件完全无法区分。

决定：按键按下计时是一次性的——仅当计时为 0（全新按下）时启动，计时运行期间的重复按下事件不刷新计时，超过自动释放延迟即强制释放。代价是用户合法长按（超过自动释放延迟，如 Shift+方向键选长文、按住退格删长句）会被周期性强制释放并重新按下（抖动），用户明确接受该代价（使用场景为打字、非游戏，且信号故障过于频繁）。

已拒绝的替代方案：(1) 重复按下事件刷新计时——会使释放丢失型卡键（最常见类型）永远得不到修复；(2) 以重复间隔是否均匀识别真人长按并豁免——引入新的误判面，且把最常见的故障漏掉。
